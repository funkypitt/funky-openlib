OpenLibe e-Ink Remix

Open-source e-ink optimized e-book reader with library catalogue search.

Overview

Cross-platform e-book reader (Flutter) optimized for e-ink displays. Paginated EPUB reading with adaptive font sizing, high-contrast themes, and tap zones designed for e-paper. Browse and download from online library catalogues, manage a local collection, and read offline.

Remixed by funkypitt from OpenLibExtended by warreth and OpenLib by dstark5.

Features

  • E-ink optimised reader — paginated EPUB (epub.js) with adaptive font sizing, high-contrast dark/light themes, scroll mode also available
  • Library search — search and browse online library catalogues; filter by language, extension, year
  • Resilient downloads — multi-instance engine that auto-balances and fails over between mirrors
  • Library management — track your collection, discover trending books, export files
  • Cross-platform — Android, iOS, Windows, Linux, macOS

Build & install

Standard Flutter project.

git clone https://github.com/funkypitt/funky-openlib.git
cd funky-openlib
flutter pub get
flutter run

# Release builds
flutter build apk --release
flutter build appbundle --release

Pre-built APKs are available from GitHub Releases or via the F-Droid repo at https://funkypitt.github.io/fdroid-repo/repo.
